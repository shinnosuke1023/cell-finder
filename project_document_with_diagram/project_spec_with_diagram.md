
# Android Cell Logger プロジェクト - 仕様書 (図解付き)

## 概要
Android スマートフォンを用いてセル情報を収集し、偽基地局検知や基地局位置推定に利用するプロジェクト。

---

## システム構成図

```
+-------------------+         +-------------------+
| Android App       |         |  サーバー (Flask) |
|-------------------|         |-------------------|
| - CellLoggerSvc   |  --->   | - /log API        |
| - CellDataStore   |         | - /map_data       |
| - MapActivity     |  <---   | - /cell_map       |
+-------------------+         +-------------------+
```

---

## 三角測量イメージ

```
   (観測点1) * RSSI=-80dBm
                                                              \       (推定基地局位置●)
                /
   (観測点2) * RSSI=-70dBm
```

RSSIに基づき、距離が近い観測点を重み付けして基地局を推定。

## 現状の仕様
- 青点 = 観測点
- 赤点 = 基地局推定位置
- 同一 CellID & 座標は最新RSSIで更新
- サーバーを経由するモードとアプリ内完結モードあり
